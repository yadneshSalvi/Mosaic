# Local visual dependencies

Manrope and DM Sans local font bytes come from the app’s existing Fontsource dependencies; their licenses are preserved beside this file. GSAP 3.14.2 is pinned in package-lock.json and its distributed runtime banner and upstream README are preserved. Its package metadata names the Standard no-charge license at https://gsap.com/standard-license. App favicon and captured product pixels come from this repository.
