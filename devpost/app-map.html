Follow one action

  1. In the sample, mask only the client-reference region. The alternate channel route remains. findRoutes computes this from the active evidence; the UI shows the remaining route.
  2. Choose Find minimal repair. minimumRegionCut searches candidate region combinations, minimizing their count and then area. It returns the shared customer-name region.
  3. Choose Export & verify. exportSource draws into a fresh canvas, emits PNG bytes, decodes those bytes again, and invokes verifyPixels. Only actually verified regions are removed from the final graph check.
A practice to reuse
A plan is not proof of an artifact. Mosaic's output requirement became an observable test: decode the emitted PNG and compare its pixels. The empty-rectangle and nonopaque-mask regressions in tests/redaction.test.ts caught cases that a UI-only success assertion would miss. On another project, identify the delivered artifact and test that artifact independently.

What the evidence desk looks like

src/styles.css defines paper, ink, cobalt, responsive layouts, dialog styling and reduced motion. src/App.tsx owns selection, review and download interactions.

What counts as a source-backed link

src/lib/types.ts defines types and validates references. server/analysis.ts reads real image bytes, calls the model and forces every returned relation to suggested. SourceInspector lets a person review and correct a proposed region.

The fictional example

src/lib/sample.ts contains labeled deterministic annotations; scripts/generate-samples.ts makes the actual PNG sources. Both pass through the same graph and raster functions as uploads.

The verification boundary

verifyPixels checks opaque masks and unchanged unmasked pixels. It does not run OCR or discover unknown inference routes. The verification record distinguishes executed agent checks from pending human review.

Keep the useful story visible

src/lib/geometry.ts converts normalized boxes into outward-rounded pixel rectangles. maskConflicts excludes every candidate that overlaps kept pixels, including distinct region IDs. Pin the public credit and compare the one-mask and two-mask repairs. Preservation tests include impossible constraints and exact kept-pixel checks.

Ask a fresh reader without giving away the answer

src/FreshReader.tsx asks for separate consent after export. src/lib/recipient.ts builds a strict request from emitted Blobs and the starting fact only; target-name comparison stays local. server/recipient.ts forwards exact PNG bytes into a new model context. buildReaderReview creates a review workspace from exported pixels, never originals behind a mask. This fresh reading can be wrong or miss evidence.
