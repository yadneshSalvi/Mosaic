# Mosaic — Verification record

This records executed agent checks, not human approval or a privacy certification.

## Core proof

The three public sample PNGs are actual raster files, generated by `scripts/generate-samples.ts`. Their deterministic annotations create two independent directed routes. Graph tests show that removing the support client-code occurrence leaves the operations-channel route, while removing the shared customer-name occurrence cuts both. A duplicate occurrence regression preserves an unmasked parallel edge.

An independent agent compared 500 seeded random small directed graphs against a separate reachability and exhaustive cut oracle; route existence, minimal cardinality and area tie-breaking agreed. A bounded-search regression declines exact repair when enumeration truncates.

## Actual artifact proof

The parent agent used the in-app browser to inspect source regions, preview a minimal repair, export files, download `mosaic-03.png`, and open its pixels independently with Sharp. The output had exactly 31,360 changed pixels in the expected rectangle (x 100–589, y 276–339); every changed pixel was opaque dark and every other pixel matched the original. PNG chunks were IHDR/IDAT/IEND. The report contained counts and neutral filenames without protected identifiers.

Unit tests encode new PNG bytes with Sharp, decode those bytes, and run the same pixel-verification function used by the browser. Regressions reject empty coverage, invalid/NaN/out-of-bounds rectangles, incomplete masks, nonopaque pixels, changed unmasked pixels and mismatched dimensions. Browser code uses a fresh transparent canvas for emitted-byte verification, preserving the observed alpha channel.

## Limits

There is no exhaustive privacy detector. The optional post-export fresh reading is a bounded model observation with separate consent, not part of the pixel proof. Pixel proof applies to selected known evidence; graph proof applies to detected, reviewed relationships in supplied images. Human judgment about quotes, relationships and region completeness is essential. Human final review, learning reflection, demo recording and submission are pending.
