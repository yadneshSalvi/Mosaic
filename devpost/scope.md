# Mosaic
See what your screenshots reveal together, then edit the evidence that connects them.

## The Unique Kernel
Mosaic protects a chosen association across a bundle. It shows exact source-backed paths, proposes a small set of redactions that cuts every detected route, and checks the actual flattened exported pixels before reporting those routes disconnected.

## Who It's For
A designer or developer preparing a client case study with screenshots from support, project tracking, and internal directories. Today they inspect files separately and can miss what repeated identifiers reveal across files.

## The Core Loop
Open an inspectable fictional bundle or import PNG/JPEG images. Choose the protected source and target. Follow links back to visible source regions; confirm or reject suggested facts. Apply a small repair, export new images, and inspect the verification report.

## Inspiration & Identity
A precise evidence desk: warm paper, ink typography, cobalt connections, fine dot grid and tactile document cards. The interface is a working canvas rather than a marketing page. This direction is an implementation recommendation under delegated design authority.

## Why This Matters to the Learner
The learner selected Mosaic for this hackathon and requested meticulous planning, polished implementation, local verification and incremental public commits. No additional personal motivation or learning outcome was supplied.

## What "Working" Looks Like
Three actual fixture images reveal Incident 042 → client C-17 → Project Cedar → Northstar Health, with a second route via an operations channel. A recommended customer-name mask breaks both routes. Downloaded PNG bytes are decoded and checked; useful unmasked content remains. An import flow analyzes new files and lets the user ground proposed facts.

## The POC Boundary
One in-memory workspace, 2–6 PNG/JPEG images, directed typed evidence, bounded route search, exact minimal region cut for supported small graphs, real raster export and observed pixel checks. Sample works offline/keyless; optional live extraction uses a server-side key with explicit cloud consent.

## Later
Local OCR, more formats, manually drawn redaction regions, saved workspaces, stronger post-export re-extraction and independent inference evaluation.

## Explicitly Cut
Accounts/database/collaboration: unrelated to the proof. PDF: adds parsing and hidden layers before image loop is proven. Generic privacy scoring and safety guarantees: not justified by bounded evidence. Deployment: optional and not authorized in this phase.
